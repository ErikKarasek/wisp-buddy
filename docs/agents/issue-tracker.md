# Issue tracker: GitHub

Issues for this repo live as GitHub issues in `ErikKarasek/wisp-buddy`, managed with the `gh` CLI.

**Before any issue operation, load the `gh-issue-conventions` skill.** It is the
canonical source for the `gh` commands, the triage labels, the sub-issue and
dependency model, and the `/wayfinder` map. This file deliberately holds no copy
of it, so the two can't drift.

Repo-specific notes:

- This repo is public, so issues and their bodies are public. Don't put anything private in one.
